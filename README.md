# True Tech Sprint

Solutions for the True Tech Sprint series — short online IT competitions with challenges from MTS Web Services (MWS). The series ran as three one-week tracks, one after another; each track's folder holds one subfolder per task with the verbatim statement and the submitted solution.

| Track | Dates | What it is |
| --- | --- | --- |
| [Prompt engineering](prompt-engineering/) | 27.07 – 02.08 | Five prompt-writing tasks — draft prompts that make the model produce a required output, judged on expert scoring and speed |
| [Development](development/) | 10.08 – 16.08 | Three algorithmic problems in Python, solved via the MWS DevTools plugin, judged on speed and hidden tests |
| [DevOps](devops/) | 24.08 – 30.08 | Five Kubernetes engineering tasks (GitLab CI, fault tolerance, debug, monitoring, logging) on a live cluster |
