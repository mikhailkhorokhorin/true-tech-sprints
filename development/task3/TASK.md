# Task 3. k-stable MTS-strings

**Type:** Algorithmic · **Points:** 100 · **Time limit:** 3 seconds · **Memory limit:** 1024 MB

## Statement

Call a string made of uppercase Latin letters an MTS-string if some (possibly zero) number of letters can be removed from it so that the string MTS is obtained.

Call a string a k-stable MTS-string if, under any split of the string into k contiguous substrings, at least one of the substrings is an MTS-string.

For given n and k, find the remainder when the number of k-stable MTS-strings of length n is divided by 998244353.

## Input

The first line contains two integers n and k (1 ≤ n, k ≤ 3·10^4).

## Output

Print one integer — the remainder when the number of k-stable MTS-strings of length n is divided by 998244353.
