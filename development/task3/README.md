# Task 3. k-stable MTS-strings

A string of uppercase Latin letters is an MTS-string if MTS can be obtained from it as a subsequence. It is k-stable if every split into k contiguous substrings leaves at least one part that is an MTS-string. Count the k-stable MTS-strings of length n modulo 998244353.
