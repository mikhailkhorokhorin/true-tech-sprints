# Task 3. Where AI saves my time: a personal audit

**Type:** Text · **Points:** 2 · **Answer limit:** 5000 characters · **Attempts:** unlimited

## Statement

Describe your regular work tasks and figure out where AI can help you save time.

Build a table: in which tasks and at which stages you can use AI, how exactly it helps, and how much time per week it saves.

You need to list 5–10 use cases.

Base it on your real work tasks.

Start by writing down 5–10 tasks you perform regularly. For each task specify:

- What exactly you do
- How often you perform the task
- How long it usually takes
- Where AI can be applied
- What exactly AI does
- What stays with you
- How much time it saves per run

**Important:** pick only the scenarios you actually use in your work.
